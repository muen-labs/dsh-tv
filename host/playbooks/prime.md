# Prime Video — playbook

Package `com.amazon.amazonvideo.livingroom`
Role: subscription streaming.

## Search
```
launch prime
key up            # top nav
key right/left    # to Search
key ok
text "k-drama"
key enter
```
Use `ui` to confirm the top-nav position. OK to open/play; BACK returns.

## Notes
- DRM playback screenshots black; use `ui`.
- Profiles may appear at launch; pick the household profile first.

# JapanTV — playbook

Package `app.japantv` · component `app.japantv/.MainActivity`
Role: Japanese live channels (list-based app).

## Navigation
- Launch; a login/terms screen may appear. Use `ui` to read it; OK to accept.
- Channel list: UP/DOWN, OK to play; BACK to list.
- Settings/quality inside the player menu (OK/MENU).

## Notes
- Not an M3U player; channels are bundled with the service.
- If playback fails, check the provider's status and network/VPN.

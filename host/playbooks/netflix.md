# Netflix — playbook

Package `com.netflix.ninja`
Role: subscription streaming.

## Search
```
launch netflix
key left          # sidebar (Search is near the top)
key up/down       # find Search
key ok
text "k-drama"
key enter
```
Use `ui` to confirm the sidebar order; OK to open, OK to play.

## Notes
- DRM: screenshots of playback are black — verify with `ui`/state, not captures.
- Series: OK on an episode; profiles can appear at launch — select the right one.
